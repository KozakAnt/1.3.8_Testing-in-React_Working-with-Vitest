# description

```
В этом задании нужно реализовать небольшую библиотеку для управления коллекцией книг. Тебе необходимо создать класс LibraryCollection с методами для добавления книг, их удаления, получения информации о книгах и количестве книг в коллекции.
Затем напишите тесты, используя Vitest, чтобы проверить корректность работы реализованных методов.

addBook(title: string, author: string): string | Error - Добавляет книгу в коллекцию, возвращает id книги. Если книга с таким названием уже существует, возвращает ошибку.
removeBook(id: string): void - Удаляет книгу по id книги.
getBookInfo(id: string): { title: string, author: string } | null - Возвращает информацию о книге по id.
getAllBooks(): Array<{ id: string, title: string, author: string }> - Возвращает список всех книг.
getBooksCount(): number - Возвращает количество книг в коллекции.

```

### запуск проекта

`npm i`
`npm run test`

## Тест-Кейсы:

1. Метод addBook:

- Добавление новой книги. При передаче уникального названия и автора книга сохраняется в коллекцию, метод возвращает строковый id, а счётчик книг увеличивается на 1;
- Добавление дубликата. При попытке добавить книгу с уже существующим названием метод возвращает объект Error, а новая запись в коллекцию не добавляется.

2. Метод removeBook:

- Удаление существующей книги. При передаче корректного id книга удаляется из коллекции, getBookInfo по этому id возвращает null, а количество книг уменьшается;
- Удаление несуществующей книги. При передаче несуществующего id метод завершается без ошибок и не меняет текущую коллекцию.

3. Метод getBookInfo:

- Поиск существующей книги. По корректному id возвращается объект строго с полями { title, author };
- Поиск отсутствующей книги. По несуществующему id возвращается null.

4. Метод getAllBooks:

- Пустая коллекция. До добавления книг метод возвращает пустой массив [];
- Список добавленных книг. После добавления нескольких книг метод возвращает массив всех объектов { id, title, author };
- Защита от внешнего изменения. Изменение массива, полученного из getAllBooks() (например, через .push()), не влияет на внутреннее состояние коллекции.

6. Метод getBooksCount:

- Начальное состояние. Для новой коллекции метод возвращает 0;
- Подсчёт после добавления. Метод возвращает точное количество книг, находящихся в коллекции в данный момент.
